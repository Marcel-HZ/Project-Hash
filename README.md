# Hash 加密原理与实战教学项目

交互式 Python 哈希加密教学项目。运行时先输入一个明文，然后按步骤跟踪该明文的编码、加密、加盐、派生、校验和彩虹表破解全过程。

## 哈希加密简介

**哈希函数**（Hash Function）是一种将任意长度的输入数据映射为固定长度输出的单向数学函数。其核心特性：

- **单向性**：无法从哈希值反推出原始输入
- **确定性**：相同输入始终产生相同输出
- **雪崩效应**：输入微小变化导致输出大幅不同
- **抗碰撞性**：找到两个不同输入产生相同哈希在计算上不可行

哈希函数广泛应用于密码存储、数据完整性校验、数字签名、区块链等场景。常见的哈希算法包括 SHA-256、SHA-512、MD5（已不安全）等。

## 哈希加密原理

本项目逐步演示以下核心原理：

### 1. SHA-256 哈希
SHA-256 属于 SHA-2 家族，基于 **Merkle-Damgard 结构**：
- **填充**：消息末尾追加 1 位，补 0 至长度 ≡ 448 (mod 512)，最后写入 64 位原始长度
- **分块**：填充后按 512-bit（64 字节）分块处理
- **压缩函数**：每块经 64 轮迭代，使用逻辑函数 (Ch, Maj, Σ0, Σ1) 与模 2^32 加法混合状态
- **输出**：256-bit（32 字节）摘要，常用十六进制表示

### 2. Base64 编码
将二进制数据映射为 64 个可打印 ASCII 字符：
- 每 3 字节（24 bit）切分为 4 个 6-bit 组
- 6-bit 值映射到字符表 A-Z/a-z/0-9/+/ 
- 不足 3 字节时用 `=` 填充
- URL-safe 变体：`+`→`-`，`/`→`_`

### 3. 盐值机制
盐值 (Salt) 是密码哈希前拼接的随机数据：
- 相同密码 + 不同盐 → 不同哈希值
- 彻底消除预计算攻击（彩虹表）的优势
- 存储格式：`$algo$iter$salt$hash`

### 4. 密钥派生 (PBKDF2)
通过反复迭代 HMAC 大幅增加暴力破解成本：
- NIST 建议 2024 年起 SHA-256 迭代次数 ≥ 600,000
- 单次哈希纳秒级 → PBKDF2 秒级，成本提升 10^6 倍
- 仅 CPU 硬化，现代替代方案为 Argon2（内存硬化）

### 5. 文件校验和
流式计算文件 SHA-256，避免大文件 OOM：
- 分块读取（8KB），内存占用恒定 O(1)
- 篡改一字节即可检测数据完整性破坏

### 6. 彩虹表攻击
时间-空间权衡攻击，对大量候选密码预计算哈希链：
- 盐值使预计算表失效（每盐需独立建表）
- 慢哈希增加单次成本，链生成/查询均被拖慢
- 4 组对比：快/慢哈希 × 有/无盐

```

├── main.py                  # 入口：输入明文 + 菜单循环 + 步骤调度

│   ├── step4_kdf.py         # PBKDF2-HMAC-SHA256 密钥派生
│   ├── step5_checksum.py    # 文件校验和生成/验证（含篡改检测）

    └── markdown.py          # Markdown 文档生成器
```

## 运行方式

```bash
python main.py
```

交互流程：
1. 输入一个明文（如 `HelloWorld2024`）
2. 菜单选择：
   - `1-6` 单步运行
   - `a` 全部运行
   - `q` 退出
3. 运行结束后自动在项目目录下生成 `HASH_DEMO_GUIDE.md`

## 6 个步骤

| 步骤 | 内容 | 输出 |
|------|------|------|
| 1 | SHA-256 基础哈希 | 明文 → Hex / Base64，雪崩效应演示 |
| 2 | Base64 编码 | 标准 / URL-safe 编码对比 |
| 3 | 盐值机制 | 无盐 vs 两次随机盐，哈希值对比 |
| 4 | PBKDF2 密钥派生 | 600k 迭代派生 32 字节密钥，输出用时 |
| 5 | 文件校验和 | 流式计算 SHA-256，篡改一字节后验证失败 |
| 6 | 彩虹表攻击 | 快/慢哈希 × 有/无盐 4 组破解对比，含构建与破解用时 |

- Python 3.10+
- 仅标准库（`tqdm` 可选，用 `try/except` 优雅降级）
